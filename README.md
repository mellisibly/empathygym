# EmpathyGym

Тренажёр эмоциональной валидации. PWA — устанавливается на телефон с сайта,
работает офлайн, данные хранятся на устройстве.

## Структура

```
index.html      — всё приложение (React, стили, теория, марафон)
trainers.js     — данные тренажёров (ГЕНЕРИРУЕТСЯ, руками не править!)
sw.js           — service worker (офлайн-кеш)
manifest.json   — PWA-манифест
vendor/         — React, ReactDOM, шрифт иконок (локально, без CDN)
tools/build_content.py — сборка контента из Kotlin-источников
```

## Как добавить или изменить кейсы, марафон, теорию

**Правило: контент правим только в Kotlin-файлах Android-проекта.**
Веб-версия генерируется из них автоматически.

1. Отредактируйте в Android-проекте:
   - `TrainerData.kt` — кейсы тренажёров (добавляйте одновременно в `getAllRu()` и `getAllEn()`, порядок тренажёров и число кейсов должны совпадать)
   - `MarathonData.kt` — задания марафона
   - `Strings.kt` — тексты теории
2. Запустите сборку (нужен Python 3):
   ```
   python3 tools/build_content.py <путь_к_папке_с_kotlin_файлами> .
   ```
   Скрипт проверит целостность (ровно один правильный ответ, непустые
   объяснения, совпадение RU/EN) и обновит `trainers.js` + `index.html`.
   При ошибке ничего не перезапишет и скажет, где проблема.
3. Поднимите версию кеша в `sw.js`: `empathygym-v5` → `v6` и т.д.
   (иначе установленные приложения не увидят обновление сразу).
4. Закоммитьте и запушьте — GitHub Pages обновится сам.

### Требования к кейсу

- Режим `c` (выбери валидацию): ровно один вариант с `correct = true`
- Режим `i` (найди инвалидацию): ровно один вариант с `invalid = true`
- Режим `m` (мультивыбор слоёв): один и более вариантов с `valid = true`
- У каждого варианта заполнен `expl` — объяснение показывается после ответа
- RU и EN версии кейса пишите парой сразу

## Данные пользователя

Прогресс, ошибки и дневник марафона лежат в localStorage с зеркальной
резервной копией в IndexedDB (восстанавливается автоматически, если браузер
очистил localStorage). Кнопки в шапке раздела «База»:
⬇ скачать резервную копию (JSON) · ⬆ восстановить из копии.

## Деплой

GitHub Pages, ветка `main`, папка `/`. После пуша обновление доходит до
установленных приложений при следующем открытии с интернетом
(service worker работает по схеме network-first).
